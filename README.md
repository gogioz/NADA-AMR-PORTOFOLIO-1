# Nada Ghonemy: Portfolio website

Next.js (App Router, JavaScript) + Tailwind CSS. Colors: moss #436B5C and rose #EFBBBD.

## Run
```bash
npm install
npm run dev     # http://localhost:3000
```

## Edit content: `data/site.js`
- **work**: films and stories. Add `video: "YOUTUBE_ID"` to play inside the site, or `url` for a link. Fix the six "Video N" titles.
- **reports**: add a `url` to any entry to link it.
- **gallery**: put images in `public/gallery/` and list them. Until then it shows frames from the films.
- **profile.photo**: put a portrait in `public/` and set `photo: "/nada.jpg"`.

## Deploy
Push to GitHub and import it on vercel.com.
